# AI 使用记录

## AI 辅助范围

本项目借助 Codex 进行需求讨论、方案设计、源码编写、合成数据与 Mock 动作设计、自动化测试、实际离线用例执行和文档草拟。代码主体与当前文档由 AI 生成并迭代。AI 也执行了本仓库记录的测试，不能将其写成候选人已经亲自执行。

运行态真实 LLM 与开发辅助分开记录。初版及图重构时没有 API；后续由候选人提供本地 DeepSeek 配置，AI 实际执行两条真实路径，证据在 `examples/deepseek-run/`。开发时使用 Codex 本身不等同于运行态模型证据。

## 已发生的候选人贡献

- 选择第二题并确定 Python CLI、本地 JSON、可替换模型接口的范围。
- 明确要求真实动态决策与 Mock 分离、预算和时间双重约束、失败保留产物、幂等及调用上限。
- 确认活动执行计划与 Agent Trace 分开，以及费用和耗时的业务口径。
- 指出不能只讨论代码结构，要求结合考题判断可行性和需要人工确认的事项。
- 决定改为 LangGraph 版本用于工程学习，要求保留业务接口、禁止硬编码重规划，并明确检查点不等于已验证故障恢复。
- 选择 DeepSeek 并填写本地API配置；密钥未包含在源码、示例文件或执行证据中。
- 亲自检查关键节点的准确性；全程投入约3小时（候选人于2026-10-31说明，非逐段精确计时）。

## LangGraph 重构中的 AI 辅助

AI 检查现有代码及官方文档，复用本机已有 LangGraph 1.2.9，将循环改为四节点 StateGraph，增加状态 reducer、内存检查点、13项图测试，并重新实际执行 CLI 样例。原26项测试保留不变；该阶段尚未运行真实模型。

## DeepSeek 验证中的 AI 辅助

AI 核对 DeepSeek 官方接口文档，补充显式配置加载、thinking参数和空白/截断响应处理，增加7项离线测试并实际运行正常输入、估算故障两条路径。模型动作由 DeepSeek 实际返回；没有预写真实Trace。AI 保留了第一条路径中不兼容参数的失败和修正，不仅展示成功结果。候选人提供密钥，API命令和结果核对由AI执行，不能改写成候选人已亲自执行。

## 尚待候选人实际完成

已记录约3小时投入及关键节点检查。具体检查了哪些节点、采用何种核对方式及个人学习总结尚未逐项补充；个人代码修改或亲自执行完整测试也未作已完成声明，不将AI执行的测试归为个人执行。后续如补充个人记录，应描述实际做过的内容。
